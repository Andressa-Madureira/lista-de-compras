# Lista de Compras

Este é um projeto interativo de uma lista de compras desenvolvida com HTML e JavaScript, que permite adicionar produtos com suas respectivas quantidades e valores, além de calcular o total acumulado. Produtos podem ser removidos individualmente.

🛠️ Tecnologias Utilizadas
<ul>
  <li>HTML: Estruturação da página</li>
  <li>JavaScript: Lógica de manipulação de dados, eventos e DOM</li>
</ul>
🚀 Funcionalidades
<ul>
  <li>Adicionar produtos com quantidade e valor</li>
  <li>Visualizar os produtos adicionados com valores individuais e totais</li>
  <li>Excluir produtos da lista, atualizando automaticamente o total acumulado</li>
</ul>

📂 Estrutura do Projeto
<ul>
  <li>HTML: Formulário para entrada de dados e exibição da lista</li>
  <li>JavaScript: Gerenciamento de dados, exibição dinâmica e interatividade</li>
</ul>

Este projeto foi desenvolvido como parte de estudos em manipulação de DOM e eventos no JavaScript, com foco em criar aplicações interativas.
